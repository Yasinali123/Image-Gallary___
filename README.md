# Premium Image Showcase Gallery

A modern, highly responsive visual media gallery web application built with HTML5, CSS3, and JavaScript. Featuring dynamic 3D carousels, customizable themes, interactive category filtering, lightbox viewer, and fluid animations.

## ✨ Key Features
- **3D Hero Carousel**: Dynamic perspective-based carousel displaying featured photography.
- **Dark/Light Theme Toggle**: Seamless mode switching with persistent preferences.
- **Interactive Collection Gallery**: Search, filter by category (Nature, Wildlife, Technology), and sort images dynamically.
- **Image Lightbox**: High-resolution view modal with navigation and detailed metadata.
- **Smooth Custom Cursor & Animations**: Premium user interface with micro-interactions and scroll animations.
- **Responsive Layout**: Designed to look stunning across desktop, tablet, and mobile displays.

## 🛠️ Built With
- **HTML5**: Semantic tags & structure.
- **CSS3**: Custom variables, Flexbox, Grid, 3D Transforms, Glassmorphism design system.
- **JavaScript (ES6+)**: Dynamic gallery rendering, state management, modal handling, smooth cursor tracking.

## 🚀 Deployment Instructions (GitHub Pages)
1. Push all code to the `main` branch:
   ```bash
   git add .
   git commit -m "Deploy Image Gallery"
   git push -u origin main
   ```
2. Enable GitHub Pages:
   - Go to `https://github.com/Yasinali123/Image-Gallary___/settings/pages`
   - Under **Source**, select **Deploy from a branch**
   - Branch: `main`, Folder: `/ (root)`
   - Click **Save**
